# 김유진 통역사 포트폴리오

한국어–포르투갈어 통역사의 소개, 경력, 통역 노트, 연락처를 보여주는 웹사이트입니다.

## 내 컴퓨터에서 보기

이 폴더의 `index.html`을 더블클릭하면 인터넷 브라우저에서 열립니다. 위쪽 메뉴를 눌러 각 화면으로 이동하세요. 별도 설치가 필요 없습니다.

## 파일 구성

- `index.html`: 소개 화면
- `experience.html`: 경력 화면
- `notes.html`: 통역 노트 화면 (현재 게시된 글 없음)
- `contact.html`: 연락처 화면
- `styles.css`: 색상, 글꼴, 화면 배치
- `public/`: 이미지와 아이콘
- `.nojekyll`: GitHub Pages에서 파일을 그대로 제공하도록 하는 빈 파일
- `.gitignore`: 임시 파일과 비밀 설정이 Git에 올라가지 않도록 하는 목록

문구를 바꾸려면 해당 HTML 파일을 메모장 같은 편집기로 열어 수정하고 저장한 뒤, 브라우저를 새로고침하세요.

## GitHub Pages에 올리기

1. GitHub 저장소 맨 위에 이 폴더 안의 파일과 `public` 폴더를 올립니다. `index.html`이 다른 폴더 안에 들어가지 않도록 합니다. `.nojekyll`도 함께 올립니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 파일을 올린 브랜치(보통 `main`)와 **/(root)**를 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 Pages에 표시되는 주소를 엽니다.

모든 내부 링크와 이미지 경로는 상대 경로라서 저장소 이름이 붙는 주소에서도 사용할 수 있습니다. 서버나 빌드 과정은 필요하지 않습니다.

## 연락처와 데이터

인스타그램과 카카오톡 아이디는 가짜 예시로 바꾸었고 인스타그램 연결 링크는 제거했습니다. 실제 연락을 받으려면 `contact.html`의 예시 값을 공개 가능한 연락처로 바꾸세요. 이름, 활동 지역, 경력은 요청에 따라 유지했습니다.

이 웹사이트에는 입력 내용을 저장하거나 글을 작성하는 기능이 없습니다. 통역 노트는 빈 목록을 표시합니다. 서버 저장 예제와 Sites·Cloudflare 전용 파일을 제거했으며, localStorage도 사용하지 않습니다.
